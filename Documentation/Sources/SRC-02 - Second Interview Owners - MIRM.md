(Q-019) Un caso que podría suceder, sería imposible, pero cuando una moto dilata mucho tiempo ¿Cobran porque la moto este ahí? Porque podría haber que el taller está lleno de motos que no encuentran la falla y ahí nadie gana nada.

Se cobra por trabajo.

- (Q-020) ¿Cómo se cancelan los créditos?  

Se pagan para un mes nada mas, a veces llegan antes, a veces se les da un poco mas. Hay algunos que se dilatan porque no son del pueblo.

- (Q-021) ¿Manejan créditos con intereses? ¿Si es así, ¿Cómo se asignan los porcentajes y cada cuanto incrementa? Por ejemplo al 10% por mes, un crédito de 4 meses.

No se ponen intereses, se cobra el total. Si dicen que es para tres meses se cobra mas, pero nadie ha pedido aún. Al 8%.

(Q-022) Si aparece una falla adicional en una reparación: ¿Se consulta con los clientes? ¿Si el cliente dice que si como se maneja? ¿Si dice que no como se maneja?  
Si el cliente le sidce que vea la falla, si solo dicen que haga algo solo eso se soluciona. 

Se consulta con el cliente, si el cliente dice que si lo cambia, es un agregado al precio. Si el cliente dice que no, se le entrega asi, no se le da garantia de que saldra bien porque uno le advirió.

- (Q-023) ¿Piensan pedir cedula para reparaciones?

Los insumos se le dicen a los liquido de barra y lubricantes asi.
