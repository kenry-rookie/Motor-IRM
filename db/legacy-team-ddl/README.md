# DDL original del equipo (histórico)

Estos archivos son el DDL y los datos de prueba que el equipo escribió a mano
antes de pasar a Prisma (S5, DEC-034). **Ya no crean la base de la aplicación**:
desde DEC-040 la única fuente del esquema son las migraciones de
`prisma/migrations/`, y `db/01_schema.sql` se genera de ellas.

Se conservan como evidencia del trabajo de la clase (modelo relacional,
normalización, restricciones). Los nombres y teléfonos del personal en
`03_seed_demo.sql` se cambiaron por datos ficticios (prompt v2, §14).
